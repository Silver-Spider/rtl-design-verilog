# Digital VLSI Design with Verilog

Personal RTL Design Portfolio built while learning Verilog HDL and Digital VLSI Design.

## Tools

- Verilog HDL
- Xilinx Vivado
- VS Code
- Git
- GitHub

## Repository Structure

rtl/ - RTL source code

tb/ - Testbenches

waveforms/ - Simulation waveforms

reports/ - Design documentation

images/ - Logic diagrams and screenshots

vivado/ - Vivado projects (optional)
